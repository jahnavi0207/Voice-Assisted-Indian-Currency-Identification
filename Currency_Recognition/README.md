# Currency Recognition

This folder contains the software and machine learning model used to identify Indian currency denominations.

## Supported Denominations

- ₹5
- ₹10
- ₹20
- ₹50
- ₹100
- ₹200
- ₹500
- ₹2000

## Implementation

The final currency recognition system will run offline on the ESP32-CAM using C++.
